# Changelog

All notable user-visible changes to VidStow are documented here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and versions follow semantic versioning where practical for a desktop
application.

## [Unreleased]

### Added

- Cross-platform release packaging for macOS, Windows, and Linux.
- GitHub Actions CI and tagged-release workflows.
- Portable Windows zip and NSIS installer packaging that includes
  `ytdlp-js-helper.exe`.
- Launch and signing documentation for the first public release.

## [0.1.0] - 2026-08-10

### Added

- First public VidStow desktop release for public single-video YouTube URLs.
- Analyze, quality presets, download queue, history, and FFmpeg diagnostics.
- Packaged `ytdlp-js-helper` runtime on every platform.
- Unsigned-install guidance for Gatekeeper and SmartScreen.
